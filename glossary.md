# Справочник: обороты, фразы, термины

Читается по требованию, когда пишется длинный текст: README, инструкция, документ, письмо, описание задачи. Принципы — в `rules.md`.

Встретил оборот из левой колонки — замени. Похожего в таблицах нет — действуй по принципам.

## Обороты

| Калька | По-русски |
|---|---|
| X является Y | X — Y: «Git является системой контроля версий» → «Git — система контроля версий» |
| данный: «в данном случае», «данный файл» | «в этом случае», «этот файл», «здесь», «так» |
| осуществлять, производить, проводить + существительное: «осуществлять проверку», «производить расчёт» | глагол: «проверять», «считать» |
| для того чтобы, в целях, с целью | чтобы, для |
| в случае, если; при условии, что | если |
| в связи с тем, что; по причине того, что | так как, потому что, из-за |
| на данный момент, на текущий момент, в данный момент времени | сейчас, пока |
| имеет место; представляет собой | есть, происходит; тире или «это» |
| является возможным, является необходимым | можно, нужно |
| существует несколько способов; не существует способа | можно сделать по-разному; нельзя, нет способа |
| когда дело доходит до X | что касается X; с X; в X |
| в то время как (для противопоставления) | а, но, зато, тогда как |
| в рамках, в контексте, на уровне | в, на, при, для — или убрать |
| основываясь на; в соответствии с | по, согласно, судя по |
| в процессе (during): «в процессе установки» | «при установке», «во время установки» |
| на высоком уровне; глубокое погружение | в общих чертах; подробный разбор |
| имеет смысл (makes sense) | логично, разумно, понятно; часто — просто «да» |
| не имеет смысла | непонятно; бессмысленно; «зачем это?» |
| потерпеть неудачу (fail) | не сработать, не пройти, упасть, выдать ошибку |
| предоставить (provide) | дать, показать, сообщить. Кроме устойчивых: «предоставить доступ», «предоставить право» |
| обеспечить (ensure) | сделать так, чтобы; добиться; гарантировать |
| реализовать (implement) | сделать, добавить, написать |
| соответствующий (corresponding, relevant) | нужный, подходящий; чаще — просто убрать |

## Фразы в разговоре и письме

| Калька | По-русски |
|---|---|
| «Я ценю это» (I appreciate it) | «Спасибо» |
| «Звучит хорошо» (Sounds good) | «Хорошо», «договорились» |
| «Работает для меня» (Works for me) | «Мне подходит», «подходит» |
| «Имеет ли это смысл?» (Does that make sense?) | «Понятно?» |
| «Я борюсь с этим» (I'm struggling with) | «Не могу разобраться с …», «никак не получается …» |
| «Не стесняйтесь» (Feel free) | «Можете …» — или просто повелительное наклонение |
| «Пожалуйста, найдите во вложении» (Please find attached) | «Файл — во вложении», «отправляю файл» |
| «Держите меня в курсе» (Keep me posted) | «Напишите, как …», «сообщите о результате» |
| «Я вернусь к вам с ответом» (I'll get back to you) | «Отвечу до пятницы», «напишу, как …» |

## Термины

| По-английски | По-русски | Не так |
|---|---|---|
| production | продакшен; в документах — боевой сервер, промышленная эксплуатация | производственная среда, производство |
| production-ready | готовый к промышленной эксплуатации, можно выкладывать в продакшен | готовый к производству |
| fail | не пройти, не сработать, упасть | потерпеть неудачу |
| abort | прервать | абортировать |
| crash | сбой, аварийное завершение | крушение |
| thread | поток | нить |
| deadlock | взаимоблокировка | — |
| collision (хешей) | коллизия | столкновение |
| override | переопределить | перекрыть |
| placeholder (в поле ввода) | подсказка в поле, плейсхолдер | заполнитель, заглушка |
| responsive | адаптивный | отзывчивый |
| user-friendly | удобный | дружелюбный к пользователю |
| download | скачать, скачивание | загрузить: непонятно, откуда и куда |
| pull request | PR, пулреквест | запрос на вытягивание |
| learn more | подробнее | узнать больше |
| contact us | контакты | свяжитесь с нами |
| prerequisites | что понадобится | предварительные требования |
| FAQ | вопросы и ответы | часто задаваемые вопросы |
